# Git 菜单工具（GitMenuTool）

纯 Win32 C++ 编写的 Git 图形化菜单工具，单文件单 exe、零运行时依赖（Win7 SP1 ～ Win11 直接双击可用），
面向不熟悉 git 命令行的同事：常用 git 操作全部图形化，输出区完整回显命令与结果，学习、生产两用。

## 功能总览

- **顶栏流程区**：路径输入/打开、克隆仓库、⟳刷新状态、⚙修改全局配置（user.name/email + 默认分支下拉）、✚初始化仓库、⤓一键配置ignore（勾选生成 Keil 固件项目规则并自动首提）、>_打开.gitignore、清空Git重来
- **左侧菜单（远端/日常/标签/分支/撤销/冲突处理 六类）**：配置远程、推送(commit)、强制推送、拉取、查看历史/某次提交、打标签/推标签、分支切换/合并/删除、跳转与回main、stash 收起恢复、各类撤销（--amend/revert/reset）、合并冲突处理（采用我方/对方、标记解决、放弃合并）等
- **流程卡**：① 全局配置 → ② 初始化仓库 → ③ 配置ignore → ④ 首次提交 → ⑤ 远端+首推(可选)；未完成环节左栏置灰锁定，防跳步
- **命令输入行**：直接敲 git 命令（自动补 `git` 前缀、自动带仓库目录）
- 状态卡实时显示分支/上下游/改动数/远端地址（可点击打开浏览器）
- 推送内置保护：无上游自动 `push -u`；远端为无关历史时弹窗确认强制覆盖；凭据失效给出处置提示

## 构建

```
build.bat
```

- 依赖：Visual Studio 2022（MSVC x86/x64 工具集），脚本自动经 vsware 定位
- 编译参数：`cl /std:c++17 /utf-8 /MT`（静态链接，免 UCRT 分发）
- 产物 `GitMenuTool.exe` 生成在本目录，源码即单文件 `main.cpp`
- **重新编译前必须关闭正在运行的 GitMenuTool.exe**（否则 LNK1104 文件占用）

## 使用要点

1. 双击 `GitMenuTool.exe`，顶部输入（或点【打开】选）仓库目录
2. 新目录按流程卡从 ① 走到 ④；已有仓库直接用左侧菜单
3. 输出区黑底回显每条命令的完整输出，聚焦后 Ctrl+C 可复制全部日志
4. `last_dir.txt` 为工具自动记录的上次目录（运行态文件，已 ignore）
